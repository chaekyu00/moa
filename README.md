# 모아 - 공부 관리 웹 앱 (웹 배포용)

## 실행 방법
- `index.html`을 Chrome, Edge, Safari 등 최신 브라우저에서 열면 실행됩니다.
- GitHub Pages에 올리면 별도 설치 없이 링크로 공유할 수 있습니다.
- 서버나 유료 API를 사용하지 않는 정적 웹 앱입니다.

## 포함 기능
- 타이머: 뽀모도로, 일반 타이머, 스톱워치, 일시정지/이어하기, 과목·공부 내용 기록
- 단어장: 단어 추가·수정·삭제, 검색, 상태·분류·우선순위 필터, 정렬
- 단어 학습: 뜻 고르기, 스펠링 쓰기, 뜻 직접 쓰기, 카드 넘기기, 문맥 빈칸, 유형 섞기
- 복습: 복습 예정·전체·새로운·오답·취약 단어 선택, 간격 반복 일정
- CSV: 단어 가져오기 및 내보내기 (기존 앱 CSV 열 이름도 일부 인식)
- 영어 자료: 직접 입력 및 TXT/CSV/PDF/DOCX/PPTX 업로드, 단어 후보 추출, 자료 저장, 단어장 추가
- 플래너: 일일 목표, 주간·월간 공부 시간 그래프, 과목별 공부 시간, 연속 학습일, 수동 기록 추가 및 삭제
- 캘린더: 날짜별 할 일 추가·완료·삭제
- 설정: 라이트/다크 모드, 글자 크기, 메뉴 색, 타이머 시간, 동기부여 문구 및 위치·변경 주기
- 데이터: JSON 백업·복원, 기존 Thonny 앱 백업 JSON 가져오기 지원

## 중요한 제한 사항
- 각 사용자의 기록은 해당 브라우저의 `localStorage`에 저장됩니다. 다른 사람과 섞이지 않지만, 다른 기기나 브라우저와 자동 동기화되지는 않습니다.
- 브라우저 데이터 삭제 전에 설정 메뉴에서 백업을 내려받는 것을 권장합니다.
- 기존 Thonny 앱의 백업은 단어, 공부 기록, 할 일, 문구, 설정, 영어 자료 중 읽을 수 있는 항목을 가져옵니다. 일부 세부 필드는 웹 버전 구조에 맞춰 변환됩니다.
- 영어 자료 분석은 외부 AI를 호출하지 않는 오프라인 단어 후보 추출 방식입니다. 문맥에 맞는 뜻과 품사는 사용자가 직접 확인해 입력해야 합니다. Gemini API 기능은 포함하지 않습니다.
- PDF/DOCX/PPTX 텍스트 추출은 CDN에서 PDF.js/JSZip 라이브러리를 불러오므로 인터넷 연결이 필요합니다. TXT/CSV는 브라우저에서 직접 읽습니다.
- 파일 업로드 최대 크기는 5MB입니다. 이미지로만 된 스캔 PDF는 텍스트를 추출하지 못할 수 있습니다.
- 이 버전은 기존 Tkinter 앱을 웹 브라우저용으로 옮긴 버전입니다. 화면과 일부 동작은 웹 환경에 맞게 재구성되었으며, 원본 데스크톱 앱의 모든 세부 동작과 완전히 동일하지는 않습니다.

## GitHub Pages 배포
1. GitHub에 로그인하고 새 저장소(repository)를 만듭니다. 예: `moa-study-app`
2. 저장소 공개 범위를 `Public`으로 설정합니다. GitHub Free에서는 공개 저장소로 Pages를 사용할 수 있습니다.
3. 이 폴더의 `index.html`, `README.md`, `.nojekyll` 파일을 저장소 최상위(root)에 업로드합니다.
4. 저장소의 `Settings` → `Pages`로 이동합니다.
5. `Build and deployment`의 `Source`에서 `Deploy from a branch`를 선택합니다.
6. Branch는 `main`, Folder는 `/(root)`로 선택하고 `Save`를 누릅니다.
7. 배포가 끝나면 Pages 화면에 표시되는 주소를 동아리 친구들에게 공유합니다. 주소 형식은 보통 `https://깃허브아이디.github.io/moa-study-app/`입니다.

`index.html`을 저장소 최상위에 두어야 합니다. GitHub Pages는 정적 HTML/CSS/JavaScript를 게시하며, 서버에서 실행되는 Python/Tkinter 코드는 실행하지 않습니다.
